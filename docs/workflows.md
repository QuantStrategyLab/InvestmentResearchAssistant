# 研究流程

两条流程都停在研究卡片和人的决定。`execution_allowed` 保持 false。不要写目标股数、订单或账户。

X 主题发现不是每项研究的必经步骤。没有候选讨论时，直接走流程 A。

## 流程 A

输入是人给出的候选，或旧顾问系统给出的标的和理由。标的必须同时有 ticker 和交易所。

1. 用 fact-check 的方法核对主张和数字。取不到一手来源就弃权，不要用记忆填数。
2. 材料属于财报时用 earnings-preview，属于事件日历时用 catalyst-calendar，属于 ETF 时用 etf-analysis。不要为了走完流程把三种都跑一遍。
3. 用 bear-case 的方法列出相反证据。
4. 用对抗性审查检查主张是否被证据支持。不要使用原技能里的工厂路径、Firstmate 或“使观点生效”。
5. 输出一张研究卡片。人决定是否采用。本仓库不把卡片送进下单流程，也不要求把私人研究写进 QAR。

## 流程 B

1. 只在需要公开讨论线索时，使用 X 主题发现。范围是美国股票和 ETF。
2. 记录帖子的发布时间与取回时间。互动数不是资金流。
3. 按规范链接去重。转载标记为 duplicate，旧闻标为 stale。
4. 无法追溯到可点击 URL 的条目不要进入支持状态。
5. 剩余条目进入流程 A。

取回失败时使用 unavailable、blocked 或 abstain。说明“不能证明没有新闻”。谣言保持 rumor，不要写成已证实。
